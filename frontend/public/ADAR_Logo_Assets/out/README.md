# ADAR Logo Asset Package

Generated from the original ADAR logo (pin + house mark, brush-lettered wordmark, "book form anywhere" tagline).

## What's inside

| Folder | Contents |
|---|---|
| `primary-logo/` | Full lockup (symbol + wordmark + tagline) — SVG and PNG (2000px & 800px), transparent background |
| `symbol/` | Pin+house mark alone — true vector SVG and 2000px PNG, transparent background |
| `wordmark/` | "ADAR" lettering alone (PNG + SVG), and wordmark+tagline stacked (PNG) |
| `favicon/` | favicon.ico (multi-size), individual PNGs (16–512px), apple-touch-icon.png |
| `light/` | Off-white ink versions of the logo/symbol/wordmark, for use on dark backgrounds |
| `dark/` | Original dark-ink versions, for use on light backgrounds |
| `transparent/` | General-use full lockup, transparent PNG, 2000×2000 |
| `social/` | 1024×1024 profile icon — one opaque version (brand background) and one transparent |
| `og/` | 1200×630 link-preview (Open Graph) image on brand background |

## Notes on the SVGs

- **`symbol.svg`** (and its light/dark variants) is a **true hand-built vector**: a solid pin shape with the house rendered as a real cutout mask, so it scales to any size with no quality loss and lets whatever's behind it show through the house, just like the original mark.
- **Wordmark and primary-logo SVGs** wrap a high-resolution embedded raster of the brush-lettered "ADAR" type. That lettering is hand-drawn/painterly rather than geometric, so it isn't auto-vectorized here — the SVG file still scales as a container and displays crisply in browsers, but the letterforms themselves are raster, not paths. If you need true vector outlines of the wordmark (e.g., for large-format signage or editing the letterforms), a proper hand-trace in Illustrator would be the next step.
